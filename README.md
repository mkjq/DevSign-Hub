## Tools

**Core developer utilities (15)**
JSON formatter & validator · JWT decoder · universal code converter · regex tester with AI explainer · Base64 text & file converter · crontab generator · HTML/CSS/JS minifier · SQL formatter · Markdown live editor · URL encoder/decoder · code diff checker · UUID v4 generator · string case converter · epoch timestamp converter · DNS & WHOIS lookup

**UI, UX & design (10)**
SVG optimizer · AI colour palette generator · image format converter · WCAG contrast checker · CSS glassmorphism builder · multi-layer shadow builder · aspect ratio resizer · multi-platform icon packer · font pairing assistant · Lottie animation previewer

**Data, security & network (5)**
NFC payload parser · cryptographic hash generator · secure password generator · YAML → JSON converter · ASCII art generator

Each tool lives on its own page under `src/app/tools/<tool>` and runs in the browser.

## Run locally

```bash
npm install
npm run dev          # http://localhost:3000
npm run build        # production build
```
